# Динамичен масив - 27.10.2026


## Задачи

### Задача 1.

Реализирайте структурата от данни сортиран масив. Трябва да изпълнява следните условия:

- трябва да работи за всеки тип, който притежава конструктор по подразбиране

- трябва да поддържа използване на подадена функция за сравнение

- след изпълнението на всяка член функция на класа, той трябва да остане сортиран

Трябва да има следните възможности:

- ```bool empty()``` - проверка дали масива е празен
- ```size_t size()``` - връща броя на елементите в масива
- ```iterator begin()```, ```iterator end()``` - начален и краен итератор // _Подсказка:_ Тези итератори трябва да са константни за коректната работа на класа 
- ```void insert(T element)``` - добавяне на елемент
- ```void remove(iterator it)``` - премахване на елемент, при подаден итератор
- ```void remove(iterator begin, iterator end)``` - премахване на интервал от елементи, при подадени итератор на началото и итератор на края на интервала
- ```void remove(<подходящ тип> condition)``` - премахване на елементи, отговарящи на дадено условие
- ```T operator[](size\_t index)``` - пряк достъп до елемент, при подаден индекс // _Подсказка:_ Не позволявайте директна модификация на елемент чрез operator[]
- ```bool contains(T element)``` - проверка дали масива съдържа даден елемент
- ```iterator find(T element)``` - връща итератора на подадения елемент ако съществува и невалиден итератор ако не съществува
- ```size_t count(T element)``` - връща броя на елементите в масива, които съвпадат с подадения елемент

Опитайте се да постигнете оптимални сложности за алгоритмите и спазвайте добрите практики на обектно ориентираното програмиране в C++
